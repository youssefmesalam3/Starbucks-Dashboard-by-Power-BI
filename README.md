☕ Starbucks Beverage Analytics Dashboard

## 📌 Project Overview

The **Starbucks Beverage Analytics Dashboard** is an interactive Power BI dashboard designed to analyze beverage nutrition, caffeine levels, sugar content, and category distribution across Starbucks products.

The project transforms raw beverage data into actionable insights using **Power Query for data cleaning and transformation** and **DAX for KPI calculations and analytical measures**. The dashboard helps users explore beverage characteristics, compare categories, and identify high-calorie and high-caffeine products.

### 1. Data Preparation
- Imported the beverage dataset into Power BI.

### 2. Data Modeling

### 3. Data Analysis

### 4. Dashboard Development

## 💡 Key Insights

- **Coffee** has the highest average caffeine content.
- **Frappuccino and Signature Espresso beverages** tend to have the highest calorie levels.
- **White Chocolate Mocha** is among the highest-calorie beverages.
- Beverage categories show significant variation in sugar and caffeine content.
- The dashboard helps identify healthier and lower-calorie beverage options.
